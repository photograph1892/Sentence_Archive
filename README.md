# 문장달력소

문장을 수집하고, 저장한 문장 중 하나를 매일 달력 화면에 보여 주는 개인용 웹사이트입니다.

## 주요 기능

- 오늘의 날짜·요일·시간 표시
- 저장된 문장 중 하루 한 번 문장 선정
- 서랍에서 저장한 문장 조회 및 삭제
- 바인더 형태의 수집 페이지에서 문장 작성·편집
- 문장 하이라이트와 대표 문장 선택
- 라이트·다크 모드
- 계절별 캐릭터 메시지
- 브라우저 IndexedDB와 localStorage를 이용한 기기 내 저장

## 실행

별도의 설치나 빌드 없이 `index.html`을 열어 사용할 수 있습니다.

GitHub Pages에서는 저장소 루트의 `index.html`이 바로 실행됩니다.

## 데이터 안내

작성한 문장은 사용 중인 브라우저와 기기에만 저장됩니다. 다른 기기와 자동으로 동기화되지 않으며, 브라우저 데이터를 삭제하면 작성 내용도 함께 사라질 수 있습니다.
